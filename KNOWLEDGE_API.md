# Bilgi Merkezi ikinci aşama

Vite geliştirme sunucusuna bağlı sunucu API'si `server/api.ts` içinde. Gizli anahtarlar yalnızca Node tarafındaki `process.env` üzerinden okunur; React içinde tutulmaz. `OPENAI_API_KEY`, `AI_MODEL` (OpenAI Responses API uyumlu model), `AI_EMBEDDING_MODEL` (OpenAI embeddings modeli) ve `ADMIN_API_TOKEN` sunucu ortamında ayarlanmalıdır. OpenAI Responses (`/v1/responses`) ve embeddings (`/v1/embeddings`) uçları sunucudan doğrudan HTTPS ile çağrılır; ayrıca SDK kurulumu gerekmez. Eksik AI yapılandırmasında `/analyze` ve `/answer` HTTP 503 döndürür; `/search` ve `/answer` ayrıca `AI_EMBEDDING_MODEL` gerektirir. Yanıt `AI servisi yapılandırılmamış.` mesajıdır; eksik değişken yalnızca sunucu günlüğüne yazılır. Sahte analiz/cevap üretilmez. Yönetici uçları, sunucu tarafında `ADMIN_API_TOKEN` ile karşılaştırılan `Authorization: Bearer ...` ister. Bu geliştirme amaçlı paylaşımlı anahtar üretimde kurumsal oturum/rol ve CSRF korumasıyla değiştirilmelidir; sadece güvenilir yerel ağda kullanılmalıdır. Anahtar tarayıcıya admin tarafından girildiği için üretimde tarayıcıda saklanan sır olarak kabul edilmemelidir.

`server/engine.ts`: KnowledgeStore soyutlaması + yerel kalıcı JSON dosyası (`.data/knowledge.json`, git dışında), AIProvider arayüzü, anahtar kelime retrieval ve KnowledgeService. JSON dosyası prototip içindir; eşzamanlı süreçler / büyük ölçek için uygun değildir. PostgreSQL/Supabase entegrasyonu `KnowledgeStore` implementasyonu ile yapılabilir. `server/provider.ts` OpenAI adapter'ıdır; API anahtarı yokken erişilmez. Uzun girişler 10 MB ile sınırlandırılır; analiz sırasında metin yaklaşık 12.000 karakterlik bloklara ayrılır. Birden çok blok varsa AI ikinci bir geçişte tüm parça başlıklarını ve kaynak özetlerini görerek anlamlarına göre yeniden gruplar; bu geçiş yalnızca var olan parçaların indekslerini yeniden düzenleyebilir. Kaynak metindeki her boşluk dışı karakter doğrulanmış kaynak alıntılarıyla kapsanmazsa analiz başarısız kalır. Çok uzun belge ve model çıktı sınırlarında hata dönebilir; hatalı veya eksik çıktı yayınlanmaz.

## API (aynı köken, `/api/knowledge`)

- `POST /analyze` `{title,rawContent,previousDocumentId?}` → `AnalysisPreview` (PendingReview). Modelden `documentTitle/categories[{title,description,items[{title,content,keywords,sourceReference}]}]` biçimi beklenir. Kaynak alıntısı ham metinde harfiyen bulunmalı; içerik yalnızca aynı alıntının büyük/küçük harf, Türkçe karakter ve açık binlik ayracı gibi güvenli biçimleme farklarını taşıyabilir. Kelime ekleme/çıkarma veya sayısal değişiklik kabul edilmez. Daha karmaşık yazım düzeltmeleri güvenli biçimde otomatik doğrulanamadığı için reddedilir.
- `GET /documents/:id/preview` → `AnalysisPreview` (admin).
- `PUT /documents/:id/review` `AnalysisPreview` → `AnalysisPreview` (admin). Kaynak alıntısı metinde harfiyen bulunmalı; içerik güvenli biçimleme farkları dışında alıntıyla eşleşmeli. Yeni parça ekleme/düzenleme/silme bu kuraldan geçer.
- `POST /documents/:id/publish` → `AnalysisPreview` (admin). Onay ile yayımlanır; önceki sürüm arşivlenir.
- `POST /documents/:id/reject` → `AnalysisPreview` (admin). Reddedilen taslak arşivlenir.
- `POST /search` `{query}` → `RetrievalResult[]`. Yalnızca Published belge ve Published parçalar. `AI_EMBEDDING_MODEL` sunucu ortamında ayarlanmalıdır: OpenAI embedding ile kosinüs benzerliği ve mevcut anahtar kelime araması birlikte kullanılır; ayarlanmazsa HTTP 503 döner, sessiz keyword fallback yapılmaz. Embedding endeksi şu an kalıcı değildir; yayınlı içerikler sorgu sırasında yeniden gömülür. Büyük koleksiyonlar için kalıcı vektör dizini gerekir.
- `POST /answer` `{question,conversationId?}` → `KnowledgeAnswer` (`answer`, `sources`, `confidence`, `found`; önceki istemciler için `text`, `citations`, `sufficient` de korunur). `conversationId` için son dört soru 30 dakika boyunca yalnızca sunucu belleğinde tutulur; yeniden başlatmada silinir. AI önce takip sorusunu arama sorgusuna dönüştürür; geçmiş cevapların hiçbiri kaynak olarak kullanılmaz. Yalnızca yayınlı parçalardan arama yapar; model yanıtı bir yayınlı içerikten harfiyen bir alıntı değilse doğrulanmış bilgi yok mesajı döner. Bu nedenle serbestçe yeniden yazılmış doğal yanıtlar henüz desteklenmez.

Model: `KnowledgeDocument` sürümlü ham belge; `KnowledgeCategory` belgeye ait başlık; `KnowledgeItem` kategoriye bağlı kaynak alıntısı, ham metindeki `sourceStart/sourceEnd` karakter konumu, sürüm ve durum taşır. Draft → PendingReview → Published/Archived yaşam döngüsü; analizden önce Draft kalıcı yazılır, başarısız analizde yayınlanmamış Draft kalır, doğrulama başarılıysa PendingReview olur. Tarayıcı ses servisleri `src/knowledge/speech.ts` içinde ayrı tutulur; browser STT/TTS desteği cihaza bağlıdır.

Yerel testler `server/engine.test.ts` ve `server/validation.test.ts` dosyalarında test doubles kullanarak servis kurallarını sınar; canlı AI kalitesini veya gerçek embedding API erişimini doğrulamaz. `node --experimental-strip-types --test server/engine.test.ts` çalıştırılabilir (uygun Node sürümünde). Geliştirme sunucusunun Vite middleware'i üretim sunucusu değildir; üretimde aynı uçları gerçek güvenli sunucuya taşımak gerekir.
